# CL NLP Lab - Semester VII

Welcome to my repository for the Computational Linguistics and Natural Language Processing (CL & NLP) Lab for Semester VII. This repo contains all the experiments and related datasets we've worked on during the semester.

## Directory Structure

*   **`EXP_1/`**: Contains the first experiment notebook (`exp_1.ipynb`) along with the dataset (`employee_information_100.csv`). This experiment focuses on **Exploratory Data Analysis (EDA)**. It loads employee data, visualizes it with bar charts, scatter plots, and pie charts (e.g., average salary per department, salary vs experience), and explores basic filtering and grouping operations.
*   **`exp_2/`**: Contains the second experiment notebook (`exp2.ipynb`). This experiment focuses on **Basic Text Preprocessing for NLP**. It covers lowercasing, removing punctuation, tokenization (using manual splits, NLTK, and spaCy), and stop word removal using NLTK.
